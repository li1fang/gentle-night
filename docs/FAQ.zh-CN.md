# Gentle Night 常见问题

[English](FAQ.md) · [快速开始](../README.zh-CN.md#快速开始)

## 能让 Mac 渐渐变黑，但不锁屏吗？

可以。Gentle Night 是 macOS 菜单栏渐黑工具，通过覆盖实时桌面的视觉遮罩，默认在空闲 10 分钟后开始、累计 60 分钟全黑。键鼠活动后反向恢复，不主动调用系统锁屏、屏保或断开显示器。

系统自己的屏保仍可能按原有设置启动，需要单独配置。它不覆盖手动锁屏，也不承担隐私或安全锁定功能。

## 适合把 LG OLED 电视用作 Mac 显示器吗？

这是目标场景之一。遮罩不依赖 DDC/CI 硬件亮度控制，因此不要求电视向 macOS 暴露亮度调节接口。开发者的 LG 电视环境已运行过有时限的原生测试，但这不代表所有型号和连接方式都经过认证。

原生分辨率、HiDPI 缩放、HDR 和实际黑位需要按设备检查。二值渲染像素经过显示链路后可能被混合。[查看验证记录](VALIDATION.md)和[手动验收清单](TESTING.md)。

## 像素消隐和普通降低亮度有什么不同？

普通渐暗增加整屏黑色遮罩的不透明度。像素消隐让每个渲染像素处于完全透明或不透明黑色状态；透明处继续显示当前桌面的原色。外围先逐渐稀疏，最后中央也消失。

同一轮阈值固定，不会每帧重抽噪声。目前使用稳定的坐标哈希，尚未使用蓝噪声；具体模型见[设计说明](DESIGN.md)。

## 为什么静音视频也可能阻止渐黑？

“音频保持”检查的是音频输出流是否活跃。静音音轨、被静音的视频仍可能保持输出流活跃。这种轻量检查不测量真实响度，不录制系统音频，也不打开麦克风。

可以关闭菜单中的 **Hold while audio output is active**。精确静音检测尚未实现。状态不可用时，包括 macOS 14.2 以前，启用音频保持会保守地保持画面可见。

## 为什么鼠标指针还在？

macOS 可能把系统指针画在遮罩上方。**Try hiding cursor (experimental)** 是默认关闭的实验选项；保留其他应用焦点时能否有效隐藏还不能保证，API 返回成功也不等于已经观察到指针消失。应用不会移动鼠标来藏起它。

## 第一下点击只用于恢复吗？

不是。遮罩允许输入穿透，恢复用的第一下点击或按键也会传给底层应用，恢复时不抢焦点。盲点可能触发按钮；需要看清目标时，可先移动鼠标恢复，再点击。

## 黑屏时自动化还能继续运行吗？

桌面保持未锁定，遮罩不拦截输入，后台和 API 任务可以继续。依赖截图、OCR、像素取色或远程控制的自动化可能看到遮罩，需要分别验证。不能保证所有视觉自动化都能穿透黑色画面。

## 能保证防烧屏或节电吗？

不能。项目目标是减少空闲时可见的静态内容，但尚未测量面板节电或长期老化收益。它不能替代显示器内置的像素清理等维护功能。

## 有安装包或 Homebrew 安装命令吗？

目前没有。请按[快速开始](../README.zh-CN.md#快速开始)从源码构建。本地应用采用临时签名，尚未公证；不要把第三方下载当作官方发行。项目不要求你关闭 Gatekeeper 或移除隔离属性。

## 会保存或发送什么数据？

时间、效果和开关保存在本地 macOS UserDefaults。应用没有账户、统计或网络调用，不捕获截图或音频样本。源码构建和打开外部文档可能访问网络；可选测试脚本在 `test-results/` 保存本地日志。

## 如何移除，并恢复正常休眠？

在 ☾ 菜单选择 **Quit Gentle Night**。正常退出会移除遮罩、恢复由应用隐藏的鼠标，并释放临时防休眠状态。随后可以删除本地 `.app` 或源码目录；没有安装登录项或后台服务。

退出不会改动系统屏保或密码设置。UserDefaults 中的本地偏好可能保留；删除应用不等于重置偏好。实验性鼠标隐藏开启时的强制终止行为仍需单独验证。

## 怎样暂停或重置？

**Pause for 1 hour** 会暂时抑制渐黑。**Restore now / cancel preview** 立即移除当前效果，但不会取消已有的一小时暂停。目前尚无“提前结束暂停”的命令。短时间尝试可以使用八秒自动恢复预览。

## 如何参与？

参阅[贡献指南](../CONTRIBUTING.md)。显示缩放／HDR、光标、音频判断、无障碍和使用说明都需要改进。提交必要的设备与复现信息即可，避免附带私人桌面内容。
