# Security policy

Gentle Night is an early native macOS prototype. No published release currently carries a security support or patch-time commitment.

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/li1fang/gentle-night/security/advisories/new), rather than disclosing sensitive details in a public issue. Include the affected commit, macOS version, reproduction steps, impact and any minimal proof of concept. Do not include credentials or private desktop captures.

For ordinary bugs, use the [bug-report form](https://github.com/li1fang/gentle-night/issues/new?template=bug_report.yml).

The overlay is not a security lock. The first input passes through; it does not protect an unlocked session from someone at the keyboard. See the [FAQ](docs/FAQ.md) for permissions, data handling and removal.
